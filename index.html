Вопросы

Частые вопросы

Нужно ли уметь программировать?

Нет. Пишешь словами, что нужно, — ИИ делает код. Если что-то не так, просто скажи ему, что исправить.

ИИ входит в цену?

Да: встроенный GeodeForge AI работает сразу, без ключей и VPN (100 запросов в месяц в Базовой, 400 в Про). Можно подключить и свой ИИ без лимитов — есть бесплатные варианты (OpenRouter, Groq, локальная модель через Ollama). Для самых сложных модов лучше всего Claude.

Можно сначала попробовать?

Да. Скачай программу и нажми «Попробовать 3 дня бесплатно» — все функции Про, без ключа и оплаты. Один раз на компьютер. Потом просто введи купленный ключ — моды и настройки останутся.

Windows пишет «Система Windows защитила ваш компьютер»

Это обычное предупреждение для программ без платной цифровой подписи. Нажми «Подробнее» → «Выполнить в любом случае». Установщик скачивается только с этого сайта (GitHub).

Есть промокод?

Введи его при покупке в поле «Промокод». Друзья пользователей GeodeForge получают скидку 10% по их реферальному коду.

Как я получу ключ?

Сразу после оплаты ключ покажется на экране и придёт на почту. В программе нажми «Активировать», введи почту, пароль и ключ.

Можно поставить на два компьютера?

Аккаунт работает на одном устройстве за раз. При входе с нового ПК придёт письмо или сообщение в Telegram с кнопкой «Подтвердить вход», а старый ПК выйдет из аккаунта.

Что нужно для работы?

Windows 10/11 и интернет. Для сборки модов ничего ставить не нужно — она идёт в облаке.

Что если ключ не пришёл?

Проверь «Спам». Если и там нет — напиши нам, указав почту, на которую оформлял покупку.
